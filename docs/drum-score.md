# 在线鼓谱 PDF

## 使用

1. 打开工具箱，选择「鼓谱 PDF」；下载页也提供链接转入入口。
2. 粘贴公开 BV 视频链接、BV 号或 b23.tv 分享文字。完整链接里的 `?p=2` 等分 P 会保留。
3. 按需填写时间选段、谱区百分比；默认自动选区并在对齐时忽略固定覆盖物。
4. 点击「整理鼓谱」。真实排队与阶段信息来自服务，关闭页面不取消服务任务。
5. 完成后应用下载 PDF，使用 Android PdfRenderer 逐页预览。可放大、换纸张与每页目标行数，再保存。

保存使用设置中的自定义目录；未指定或自定义目录不可写时，默认保存到 `Download/BBDroid/鼓谱/`。文件 MIME 为 `application/pdf`。保存后的文件可通过内容 URI 打开和分享。

## 任务与排版

- 最近十个任务在本机保留，可切换、刷新、取消及重试；失败原因由服务返回。
- 支持原服务完整任务链接恢复，必须带 `#` 后的访问凭据。
- A4 / A3 / A5 纵向；每页目标行数为自动或 1–16。服务在完整谱行和可读性约束下自动调整。
- 预览直接渲染当前 PDF，因此页码、总页数和保存文件属于同一份结果。
- 新排版完整下载并通过原生 PDF 页数校验后才替换预览；失败保留旧版。
- 临时排版不覆盖原服务默认结果。可恢复默认；复制任务链接仍指向默认结果。

## 服务与限制

第三方项目：[kenqia/bilibili-drum-score-to-pdf](https://github.com/kenqia/bilibili-drum-score-to-pdf)，服务：[drum.kenqia.top](https://drum.kenqia.top/)。本版提供原生在线客户端，服务端执行原项目的图像拼接和 PDF 排版，需要联网。本版未移植 Python/OpenCV、本地视频 CLI 或 AI Agent Skill。

服务支持 10 分钟以内、约 420 万像素以内的公开白底纵向滚谱，受其网络、配额、内容支持与作者拒绝规则限制。结果默认保留 24 小时；任务链接可访问结果，请只分享给信任的人。保存到本机的文件独立于服务期限。

应用端单份 PDF 下载上限为 64 MiB，预览最多 64 页；重新排版响应上限为上游约定的 32 MiB。缓存位于应用缓存目录，可由系统回收；任务记录与凭据位于 `noBackupFilesDir`，不参与 Android 应用备份。清除应用数据会移除本机任务记录；已另行保存的 PDF 仍在保存位置。

提交只发送公开视频链接与转换选项。后续请求仅携带该任务的专属 Bearer 凭据，客户端不读取 B站登录 Cookie，不跟随服务重定向转发凭据。测试用明文 HTTP 只在 Debug 变体启用，正式包使用 HTTPS 服务。

算法忠实拼接原画面，不重新识别音符或保证音乐正确，可能保留模糊、水印、播放标记和拼接问题。演奏、打印前请逐页核对原视频。
